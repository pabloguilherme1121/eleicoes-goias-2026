# Eleições Goiás 2026

Dashboard estático e responsivo para consulta de deputados estaduais de Goiás, com composição partidária, ranking, busca, filtros e exportação CSV.

Site: https://pabloguilherme1121.github.io/eleicoes-goias-2026/

## Executar

Abra `index.html` em um navegador. Não há dependências ou etapa de build.

## Publicação

GitHub Pages: branch `main`, pasta raiz `/`.

## Dados

Conteúdo e dados preservados do arquivo HTML fornecido pelo proprietário. A publicação técnica não constitui uma auditoria dos resultados eleitorais. O painel é estático e não atualiza os dados automaticamente; as fontes indicadas estão no próprio dashboard.
